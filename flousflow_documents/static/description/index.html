Flous Flow Documents

A complete document management app for Odoo 19 Community

Folders, files, URLs, tags, granular permissions, sharing, favorites, lock/unlock, email aliases and a portal page — all in a native kanban view, functionally equivalent to the Enterprise Documents app.

Screenshots

Native kanban with preview thumbnails, tags, favorites and the Folders search panel.

Full document form: type, folder, owner, tags, contact, access rights and lock status.

Sharing wizard: internal and link rights plus partner invitations with roles and expiry.

Trash section with restore and confirmation-protected permanent delete.

Key features

Folders are documents

Nested folders with parent_path, preview thumbnails, owner avatars, colored tags, favorites and a Folders search panel.

Granular permissions

Editor / Viewer / None with folder inheritance, owner override, per-partner sharing with expiration and manager override — enforced by record rules.

Sharing wizard

Set internal & link rights and invite partners with roles and expiry dates in one dialog.

Trash with auto-purge

Soft delete, configurable retention days, restore and a confirmation-protected permanent delete.

Email alias

Give every folder an inbox — documents arrive by email.

Lock / Unlock

Check out documents so only the locker or a manager can edit.

Request, move, copy, link & portal

Ask a partner to upload a file (with an activity), bulk move/copy documents between folders (deep copy for folders), or link any document to any record in Odoo.

Portal /my/documents — partners see and download shared documents (token-protected).

Installation

Install like any Odoo module. It only depends on standard apps: base, mail, web, contacts and portal. A complete Arabic (ar_001) translation is included.
