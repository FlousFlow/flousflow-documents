# Flous Flow Documents — Odoo 19

Document management app for **Odoo 19 Community** — folders, files, URLs,
tags, granular permissions, sharing, favorites, lock/unlock, email aliases,
request-a-file, move/copy, link-to-record, portal page with token-protected
downloads, native kanban view and a full Arabic (ar_001) translation.

**Module**: [`flousflow_documents/`](./flousflow_documents)

Install it from the **Odoo Apps** web UI by adding this repository link:

```
https://github.com/FlousFlow/flousflow-documents
```

or clone it into your addons path:

```bash
git clone https://github.com/FlousFlow/flousflow-documents.git
```

Only standard Odoo apps are required: `base`, `mail`, `web`, `contacts`, `portal`.

See the [module README](./flousflow_documents/README.rst) for features,
configuration and usage.
